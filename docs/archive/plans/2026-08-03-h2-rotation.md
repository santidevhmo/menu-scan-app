# H2.2 Rotation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A menu photographed sideways is straightened before extraction, so it stops losing its printed prices — without ever rotating a menu that was already upright.

**Architecture:** The edge function reads the photo once, as today. Mistral's response already carries the pixel box of every text block (production receives them and ignores them), so `detectOrientation` decides which way up the page is for free. If it is crooked the function returns `needs_rotation` plus the first read's text, the client rotates with a library it already ships and re-submits, and the second pass keeps the corrected read only if it is positively upright AND kept its numbers. Upright menus — every menu in the suite — take exactly one OCR call and are untouched.

**Tech Stack:** Deno / TypeScript (Supabase Edge Functions), React Native + `expo-image-manipulator` `~56.0.18` (its `context.rotate(degrees)` is CLOCKWISE for positive values — verified in the installed types, and the same convention `correctionDegrees` uses, so the server's number passes through unchanged), Mistral OCR `mistral-ocr-4-0` (pinned), OpenAI `gpt-4.1-2025-04-14` (pinned).

**Spec:** `docs/superpowers/specs/2026-08-03-h2-rotation-design.md`
**Already done (evals 131/132):** `supabase/functions/analyze-menu/orientation.ts` exists and is visually confirmed 16/16 by Santiago via `scripts/probe-rotation-gallery.ts`. This plan does NOT rewrite it.

import {
  acceptRotation,
  correctionDegrees,
  detectOrientation,
  isPositivelyUpright,
  MIN_BLOCKS,
  type OcrBlock,
  printedNumbers,
} from "./orientation.ts";

/** `count` text boxes laid out as reading lines. `wide` makes them wider than
 *  tall (a page whose lines lie down); `down`/`right` set which way reading
 *  order advances, which is what separates upright from upside down. */
function page(
  count: number,
  { wide = true, down = true, right = true } = {},
): OcrBlock[] {
  return Array.from({ length: count }, (_, i) => {
    const step = down ? i : count - 1 - i;
    const cross = right ? i : count - 1 - i;
    const x = cross * 10;
    const y = step * 10;
    return {
      top_left_x: x,
      top_left_y: y,
      bottom_right_x: x + (wide ? 100 : 5),
      bottom_right_y: y + (wide ? 5 : 100),
      content: `line ${i}`,
    };
  });
}

```ts
export async function runPagedExtraction(
  photos: string[],
  mistralKey: string,
  openaiKey: string,
  ocr = ocrMistralWithRetry,
  structure = structureMenuTextWithRetry,
  pass: RotationPass = {},
): Promise<PagedExtraction> {
  // Stage-1a for every page FIRST. The old code structured each page as soon as
  // it was read; orientation has to be settled before any Stage-1b call is paid
  // for, and a crooked page's structuring would be thrown away anyway.
  const reads = await Promise.all(photos.map((photo) => ocr(photo, mistralKey)));

  if (!pass.rotated) {
    const needs_rotation = reads.flatMap((read, page) => {
      const degrees = correctionDegrees(detectOrientation(read.blocks));
      return degrees === 0 ? [] : [{ page, degrees }];
    });
    if (needs_rotation.length > 0) {
      return { needs_rotation, prior: reads.map((read) => read.markdown) };
    }
  }

  const pages = await Promise.all(reads.map(async (read) => {
    const structured = await structure(read.markdown, openaiKey);
    return {
      markdown: read.markdown,
      items: postprocessItems(structured.items as ExtractedMenuItem[]),
      raw_response: JSON.stringify({
        ocr: read.raw_response,
        structure: structured.raw_response,
      }),
    };
  }));
  const merged = pages.length > 1
    ? mergeItemSources(pages.map((page) => page.items))
    : pages[0].items;
  return {
    image_quality: { usable: true, issues: [] },
    image_layout: { dense: false, crop_direction: "none" as const },
    items: textStructureCleanup(
      merged,
      pages.map((page) => page.markdown).join("\n"),
    ),
    raw_response: JSON.stringify(
      pages.map((page) => JSON.parse(page.raw_response)),
    ),
  };
}
```

```ts
/** Rotate an image CLOCKWISE by `degrees` and return the new file's URI.
 *
 *  expo-image-manipulator's `rotate` is clockwise for positive values, which is
 *  the same convention `correctionDegrees` uses on the server — so the number
 *  the edge function sends is passed straight through, with no sign flip. Eval
 *  094 recorded a session getting exactly that sign wrong. */
export async function rotateImage(
  uri: string,
  degrees: number,
): Promise<string> {
  const context = ImageManipulator.manipulate(uri);
  context.rotate(degrees);
  const rendered = await context.renderAsync();
  const result = await rendered.saveAsync({ format: SaveFormat.JPEG });
  return result.uri;
}
```
